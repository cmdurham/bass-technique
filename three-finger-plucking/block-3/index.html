Block 3

Program

Block 3 takes the strict a–m–i cycle across string pairs. Each pair is played high string first, so every move to the lower string is a rake: the finger that played the last note on the higher string also plays the first note on the lower one, and the cycle continues from it. The move back up to the higher string is not a rake: keep the cycle going.

Exercise 1 primes the plucking hand on the D string, a different gauge and tension from the earlier blocks. Exercises 2 to 4 play four bars on each pair: the A and E strings, the D and A strings, the G and D strings, then back to the D and A strings, sixteen bars in all. The fretting hand holds one note on each string, in 7th position and in C: E and C, A and F, D and B.

The focus this block is the rake in the plucking hand, not fretting-hand coordination; that comes in Block 4. Start slowly, and use the end of each sixteen bars as the point to raise the tempo. Two notes per string is the hardest to keep at speed.

Exercise 1

Block III

Exercise 1 is plucking only: the C at the 10th fret of the D string, in 16th notes. The D string is a different gauge and tension from the earlier blocks. Keep the rhythm even, then raise the tempo. Sixteen notes don't divide by three, so each bar starts on a different finger; the cycle realigns after three bars, and the repeat returns you to a. The tempo is marked in quarter notes.

Exercise 2

Block III

Exercise 2 plays three notes on each string, one bar per string, high string first. Four bars on each pair, climbing from the A and E strings to the G and D strings and back to the D and A strings. The sixteen bars end with the cycle mid-way, so there is no repeat: to go round again, carry the cycle straight on without resetting to a, or stop and take the next pass at a faster tempo.

Exercise 3

Block III

Exercise 3 plays four notes on each string in eighth notes, so each bar is one trip across the pair. Four bars on each pair, climbing and back as in Exercise 2. As there, the sixteen bars end mid-cycle: carry the cycle straight on, or stop and raise the tempo. The tempo is marked in eighth notes.
